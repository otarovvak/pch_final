

# README 

Данный проект представляет собой веб-приложение для управления карточками следственных дел. Оно позволяет сотрудникам следственных органов создавать, редактировать, отправлять на согласование и утверждать карточки, связанные с проведением следственных действий. Приложение включает в себя систему уведомлений для информирования пользователей о статусе их действий и операций, а также использует **JWT аутентификацию** для безопасного доступа. В зависимости от роли пользователя, доступны различные функции, такие как создание и просмотр карточек, утверждение или отклонение запросов, а также управление доступом к данным. Приложение состоит из фронтенда, разработанного на React, и бэкенда на Node.js и Express.




## Начало работы

### Требования

* Node.js (рекомендуется LTS версия)
* npm (менеджер пакетов Node.js)


### Установка

1. **Клонируйте репозитории:** 

Требования
Для запуска проекта локально, необходимо установить следующее:
Node.js (рекомендуется LTS версия)
npm (менеджер пакетов Node.js)

1) Клонируйте репозиторий на свой локальный компьютер:
git clone https://github.com/otarovvak/pch_final.git
cd pch_final

2) Установите необходимые зависимости:
нужно в каждой директории
cd frontend
npm install 

cd backend
npm i

3) запустите проект в каждой директории проекта

cd backend 
node app.js

cd frontend 
npm run dev

Проект будет доступен по адресу http://localhost:5173.
Структура проекта
/frontend/src: Основная директория с исходным кодом фронтенда приложения.

/components: Компоненты интерфейса, такие как форма регистрации, профиля, уведомлений (e.g., EditCardModal.jsx, NotificationBlock.jsx).

/pages: Страницы приложения, например, страница профиля (CardCreationPage.jsx, CardDetailsPage.jsx, etc.).

/styles: CSS стили для компонентов и страниц.

/utils: Утилиты и вспомогательные функции, например, данные для регионов, должностей (data.js).

/backend: Директория с исходным кодом бэкенда.

app.js: Главный файл приложения.

/config: Файлы конфигурации.

/controllers: Контроллеры для обработки запросов (e.g. authController.js, cardController.js).

/models: Модели данных.

/routes: Роуты приложения (e.g., authRoutes.js, cardRoutes.js).

/services: Сервисы для работы с данными (e.g., authService.js, cardService.js).

/middleware: Middleware для обработки запросов.

/utils: Утилиты бэкенда.

package.json: Файл с описанием проекта и зависимостей (для фронтенда и бэкенда).
